# Roadmap de Funcionalidades Avançadas - BriefAI

## Builder de Templates

- [ ] Drag-and-drop para seções e perguntas
  - Arrastar e soltar perguntas/seções para reordenar
  - Adicionar/remover perguntas de tipos variados (texto, múltipla escolha, slider, upload, imagem)
  - Feedback visual ao arrastar
  - Salvar ordem e estrutura automaticamente

- [ ] Preview do Template/Briefing
  - Visualização em tempo real do fluxo do cliente (modal ou tela dedicada)
  - Simulação de perguntas, navegação e validações
  - Layout idêntico ao fluxo real (Typeform/chat)
  - Permitir testar diferentes tipos de perguntas e navegação
  - Ajustes rápidos a partir do preview

## Outros Itens do Roadmap

- [ ] Cobertura de testes para endpoints críticos (briefs, templates, auth)
- [ ] Polimento de responsividade e UX em telas-chave
- [ ] Exportações (PDF, JSON, ZIP) e uploads de imagens
- [ ] Fluxo de IA (sugestões, resumo, inconsistências)
- [ ] Billing/uso, limites por plano e alertas
- [ ] i18n (pt/en/es) e mensagens de erro
- [ ] Documentação para onboarding e deploy
- [ ] QA completo e preparação de release
